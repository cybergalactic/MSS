# CRAFT Library

CRAFT contains ready-to-run mathematical models and editable time-domain simulation scripts for ships, autonomous underwater vehicles (AUVs), uncrewed surface vehicles (USVs), and floating structures. It also provides a unified workflow for simulating user-defined 6-DOF marine craft from ShipX, WAMIT, or Capytaine seakeeping data. The files are compatible with MATLAB and GNU Octave.

## Modeling Workflows

### Otter maneuvering and seakeeping model

[`otter.m`](USV/models/otter.m) combines power-based added mass and radiation
damping and Capytaine hydrostatic restoring with rigid-body and payload
dynamics, nonlinear Coriolis/centripetal terms, damping, twin-pontoon
cross-flow drag, propeller thrust, and ocean currents. The hydrodynamic
matrices use the nominal 80 kg dataset, with a 55 kg hull and 25 kg payload,
and are transformed from the dataset CG to the body-frame origin CO.
Their fixed reference spectrum is independent of the wave settings selected
for an individual simulation.

[`SIMotter.m`](USV/SIMotter.m) provides a single setup GUI for PID heading
control, ALOS/ILOS waypoint guidance, ALOS guidance using Hermite splines,
current speed and direction, waves, duration, and time step. The default
model is `otter`; the legacy-model checkbox selects the first-principles
[`otter_legacy.m`](USV/models/otter_legacy.m) developed in 2019-2026.
The model calling interface and argument order are retained. Historical
results can be reproduced with the legacy model; the EKF/course-control
example `exOtter` also uses `otter_legacy`.

First-order force-RAO wave excitation is available with either model. The
loads are transformed from the nominal dataset CG to CO and applied through
the selected model's mass matrix. Waves are initially disabled; the sea-state
inputs default to Hs = 0.20 m and a peak frequency of 3.0 rad/s. The simulation
plots vessel motion, heading tracking, wave forces, the spectrum, and wave
elevation. These additions provide a unified simulation model; calibration
against measured vessel motion remains necessary for quantitative prediction.

### Craft images

Craft photographs and simulation illustrations are stored alongside the models:

- [AUV images](AUV/models/figs/), including `remus100.jpg` and `SIMremus100.jpg`.
- [USV images](USV/models/figs/), including `otter.jpg`.
- [Ship and floating-structure images](SHIP/models/figs/).

`displayVehicleData` prefers these folders when a simulator supplies an image
name, so the images do not depend on the Simulink folders being on the path.
Explicit image paths and older path-based lookups are also supported. Existing
copies in `SIMULINK/figs` are retained for the Simulink models. The REMUS
simulation illustration is stored with the AUV models.

### LAUV Marie standalone wave model

[`lauvMarie.m`](AUV/models/lauvMarie.m) is a dedicated 6-DOF model of the 2.15 m
LAUV Marie at NTNU. It combines hydrodynamic coefficients generated by
MSS-Capytaine with a power-based constant seakeeping/maneuvering model,
calibratable viscous and friction terms, and additional nonlinear damping,
cross-flow, lift, drag, and Coriolis terms. The idealized bare-hull data are
not a validated digital twin; the calibration parameters can be adjusted when
experimental data are available.

[`SIMlauvMarie.m`](AUV/SIMlauvMarie.m) is the corresponding standalone
simulation. It includes ocean currents, directional JONSWAP waves,
first-order wave loads from force RAOs with frequency-dependent depth
attenuation, MIMO depth/heading control, and ALOS guidance for 3-D path
following. It also provides LAUV-specific input and result windows, including
wave-spectrum and wave-force plots.

The same `LAUV_marie.mat` data can be opened in [`SIMhydroVessel.m`](SIMhydroVessel.m)
using **Load vessel MAT-file** for a generic hydrodynamic test. LAUV Marie
is not a named GUI preset; use `SIMlauvMarie` for the dedicated model. The
standalone LAUV pair contains the vehicle-specific nonlinear terms, calibration
parameters, controls, guidance, and wave-depth behavior.

### User-defined hydrodynamic craft

[`hydroVessel.m`](hydroVessel.m) implements a 12-state, nonlinear 6-DOF model using the common MSS `vessel` structure. [`SIMhydroVessel.m`](SIMhydroVessel.m) is an editable simulation template that can be adapted to a user-defined USV, AUV, ship, or floating structure.

The simulator includes a hydrodynamic model test GUI for quickly checking MSS-Capytaine exports. Use **Load vessel MAT-file** to open an MSS-compatible `vessel` structure directly from `MSS-Capytaine/vessels_capytaine/<family>/<case>/results/`. TestShip is the built-in demonstration; ShipX and WAMIT entries load data imported from those commercial solvers. Capytaine-generated versions are opened through the file picker. Review irregular seas, wave spectra, directional spreading, first-order wave forces, ocean currents, viscous damping, initial conditions, and heading-autopilot or dynamic-positioning settings, then click **Run simulation**. Develop vessel-specific nonlinear terms and sea-trial calibration in dedicated craft models such as `lauvMarie`. The GUI initially loads `LAUV_marie.mat` as a generic custom model and offers it as the default file-picker selection. Only the vessel MAT-file is needed; verify geometry in MSS-Capytaine before testing in MSS. Custom vessels receive conservative editable simulation defaults, including editable controller gains, while their linear damping inputs are read from `vessel.powerBased`.

Hydrodynamic vessel data and processing instructions are organized by source:

- [ShipX vessel data](../HYDRO/vessels_shipx/ShipX-Vessels.md)
- [WAMIT vessel data](../HYDRO/vessels_wamit/WAMIT-Vessels.md)
- [Capytaine vessel data](../HYDRO/vessels_capytaine/Capytaine-Vessels.md)

ShipX and WAMIT are commercial programs. The open-source [MSS-Capytaine](https://github.com/cybergalactic/MSS-Capytaine) add-on uses Capytaine to generate compatible vessel structures without commercial seakeeping software.

## Getting Started

From the MSS root directory, update the MATLAB path and run a simulation:

```matlab
mssPath
SIMremus100
```

To run the standalone LAUV Marie model with currents and waves, use:

```matlab
SIMlauvMarie
```

For the Otter setup GUI, including the legacy-model and wave selections, use:

```matlab
SIMotter
```

MATLAB users can also display the concise command-window catalogue:

```matlab
help CRAFT
```

To use the hydrodynamic workflow, run:

```matlab
SIMhydroVessel
```

The configuration and GUI helpers are located in [`utils_hydroVessel`](utils_hydroVessel/).
