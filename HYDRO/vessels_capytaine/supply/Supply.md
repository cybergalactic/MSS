# Supply vessel

`supply.mat` contains the zero-speed MSS vessel structure generated by
[MSS-Capytaine](https://github.com/cybergalactic/MSS-Capytaine) from the
`supply_mgf` case. It replaces the former ShipX supply dataset in the MSS
hydrodynamic catalogue.

The file includes rigid-body properties, frequency-dependent added mass and
radiation damping, hydrostatic restoring, force and motion RAOs, and mean
wave-drift loads. Data use forward-starboard-down axes at the center of gravity.
Stored damping inputs are `T_126 = [6.4 2.4 3.3]` s and
`delta_zeta_345 = [0 0.1 0]`. Default power-based averaging uses a JONSWAP
reference at 1.0 rad/s with gamma 3.3.

Select **Supply vessel** under **Capytaine** in `SIMhydroVessel`, or load the
file directly:

```matlab
load supply.mat vessel
vessel = computeManeuveringModel(vessel);
plotBv(vessel);
```

To regenerate in MSS-Capytaine 1.2, run `python main.py supply_mgf`.
Copy `vessels_capytaine/supply_mgf/supply.mat` into this directory.
Changing only JSON damping inputs requires `python main.py supply_mgf --update-damping`
and copying the updated MAT-file; no hydrodynamic solve is required.

These are zero-speed hydrodynamics. Forward-speed wave encounter calculations
do not supply speed-dependent added-mass or radiation-damping matrices.
