# S175 container ship

`s175.mat` contains the zero-speed MSS vessel structure generated by
[MSS-Capytaine](https://github.com/cybergalactic/MSS-Capytaine) from the
`s175_mgf` case. It replaces the former ShipX S175 dataset in the MSS
hydrodynamic catalogue.

The file includes rigid-body properties, frequency-dependent added mass and
radiation damping, hydrostatic restoring, force and motion RAOs, and mean
wave-drift loads. Data use forward-starboard-down axes at the center of gravity.
Stored damping inputs are `T_126 = [11.9 2.0 1.8]` s and
`delta_zeta_345 = [0 0.2 0]`. Default power-based averaging uses a JONSWAP
reference at 1.0 rad/s with gamma 3.3. The stored roll increment is a
case-specific setting, distinct from the general surface-vessel increment 0.1.

Select **S175 container ship** under **Capytaine** in `SIMhydroVessel`, or run:

```matlab
load s175.mat vessel
vessel = computeManeuveringModel(vessel);
plotBv(vessel);
```

To regenerate in MSS-Capytaine 1.2, run `python main.py s175_mgf`.
Copy `vessels_capytaine/s175_mgf/s175.mat` into this directory.
Changing only JSON damping inputs requires `python main.py s175_mgf --update-damping`
and copying the updated MAT-file; no hydrodynamic solve is required.

This file has one zero-speed dataset. The speed-dependent S175 used by
`exManeuveringModel` is retained separately in
[`mssExamples/data`](../../../mssExamples/data/README.md).
