# LAUV Marie

LAUV means Light Autonomous Underwater Vehicle. The LAUV platform family was
developed by the University of Porto's LSTS and is commercialized by OceanScan.
Marie is NTNU AUR-Lab's particular OceanScan LAUV.

This directory contains `LAUV_marie.mat`, an idealized submerged-body MSS
vessel structure generated by
[MSS-Capytaine](https://github.com/cybergalactic/MSS-Capytaine). The case uses
NTNU's published 2.15 m length and 34 kg mass for Marie, together with the
published 0.15 m OceanScan LAUV-family diameter.

The file contains the rigid-body mass matrix, zero-, finite-, and
infinite-frequency added mass and radiation damping, hydrostatic restoring,
power-based damping inputs, and force and motion response amplitude operators.
The stored damping inputs are `T_1236 = [50 5 5 5]` s for surge, sway,
heave, and yaw, and `delta_zeta_45 = [0.2 0.2]` for roll and pitch.

The exact hull offsets, mass distribution, centers, appendages, and propeller
geometry are not public. The model therefore uses a documented generic
tapered-cylinder hull without fins, antennas, sonar heads, or propeller. It is
a hydrodynamic example rather than a validated digital twin of Marie.

The data use MSS forward-starboard-down body axes and are referenced to the
vehicle center of gravity. The hull is placed at a mean operating center
depth of 1.0 m for the Capytaine free-surface calculation. This is a single
fixed equilibrium depth rather than a depth-averaged hydrodynamic model; the
translation is removed from the exported body-fixed CG, CB, and panel
coordinates.

## Standalone MSS craft model

The dedicated [`lauvMarie.m`](../../../CRAFT/AUV/models/lauvMarie.m) model uses this
file in a unified 6-DOF seakeeping/maneuvering formulation. The power-based
constant model is augmented by calibratable viscous and friction terms and by
nonlinear damping, cross-flow, lift, drag, and Coriolis terms.

[`SIMlauvMarie.m`](../../../CRAFT/AUV/SIMlauvMarie.m) is the corresponding
standalone simulation with ocean currents, directional JONSWAP waves,
first-order wave loads, depth/heading control, and 3-D ALOS guidance. The
1.0 m Capytaine depth is the shallow reference for the force RAOs. At greater
vehicle depths, each wave-frequency component is attenuated according to its
deep-water wave number; components are not amplified when the vehicle is
shallower than the reference. This runtime correction acts on the wave forces
only and does not change the added-mass or radiation-damping data.

Use `SIMlauvMarie` for the dedicated vessel simulation. To inspect the
exported hydrodynamics in the generic test tool, run `SIMhydroVessel` and
choose `LAUV_marie.mat` with **Load vessel MAT-file**. LAUV Marie is loaded through the custom MAT-file option; nonlinear modeling and calibration belong in the
dedicated craft model.

## Regenerating the data

Clone MSS-Capytaine separately, install its Python dependencies, and run:

```sh
python main.py LAUV_marie
```

The generated vessel file is written to
`vessels_capytaine/LAUV_marie/results/LAUV_marie.mat` in MSS-Capytaine.

Capytaine and Python are required only to regenerate the hydrodynamic data.
The included `.mat` file can be loaded and processed directly using the MSS
HYDRO functions in MATLAB or GNU Octave.

Sources: [NTNU LAUV Marie](https://www.ntnu.edu/aur-lab/lauv-marie) and
[LSTS LAUV family](https://lsts.fe.up.pt/systems/53).
