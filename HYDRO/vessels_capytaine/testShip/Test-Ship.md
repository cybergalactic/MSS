# Test ship

This directory contains an example MSS vessel structure generated by
[MSS-Capytaine](https://github.com/cybergalactic/MSS-Capytaine). The add-on
uses the open-source [Capytaine](https://capytaine.org/) boundary-element
solver to calculate hydrodynamic coefficients and exports them in the MSS
`vessel` structure format.

## File

- `testShip.mat` contains the rigid-body mass matrix, zero-, finite-, and
  infinite-frequency added mass and radiation damping, hydrostatic restoring,
  power-based damping inputs, and force and motion response amplitude
  operators for the synthetic test ship.

The data use the MSS forward-starboard-down axes and are referenced to the
vessel center of gravity. The hull and inertia values are synthetic and are
provided for demonstration rather than as a validated vessel design.

## Regenerating the data

Clone MSS-Capytaine separately from MSS, install its Python dependencies,
and run from the MSS-Capytaine project directory:

```sh
python main.py testShip
```

The generated vessel file is written to:

```text
vessels_capytaine/testShip/results/testShip.mat
```

Capytaine and Python are required only to regenerate the hydrodynamic data.
The included `.mat` file can be loaded and processed directly using the MSS
HYDRO functions in MATLAB or GNU Octave.
