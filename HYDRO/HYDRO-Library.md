# HYDRO Library

HYDRO imports, processes, inspects, and converts seakeeping data for use in MSS. The common `vessel` structure stores rigid-body properties, frequency-dependent added mass and potential damping, hydrostatic restoring matrices, response amplitude operators (RAOs), and, when computed, signed mean-drift coefficients under `vessel.drift.w` and `vessel.drift.coeff{1:3}` (surge, sway, yaw). The functions and included data are compatible with MATLAB and GNU Octave. Drift coefficients are loads per squared incident-wave amplitude; retain each dataset's documented moment reference when applying them.

## Hydrodynamic Data Sources

| Source | License | Included cases and instructions |
| --- | --- | --- |
| WAMIT | Commercial | [WAMIT vessel documentation](vessels_wamit/WAMIT-Vessels.md) |
| Capytaine through MSS-Capytaine | Open source | [Capytaine vessel documentation](vessels_capytaine/Capytaine-Vessels.md) |

[MSS-Capytaine](https://github.com/cybergalactic/MSS-Capytaine) computes 6-DOF linear potential-flow hydrodynamics with the open-source Capytaine solver and exports the results in the MSS `vessel` format. Pre-generated Capytaine examples are included and do not require Python unless they are regenerated.

The ShipX importer and catalogue have been removed. Supply and S175 now use Capytaine data. The legacy speed-dependent S175 file is retained only for [`exManeuveringModel`](../mssExamples/exManeuveringModel.m); see [`mssExamples/data`](../mssExamples/data/README.md).

## Typical Workflow

1. Import WAMIT data with `wamit2vessel`, or load a vessel generated by MSS-Capytaine.
2. Use `computeManeuveringModel` to form constant power-based added-mass, potential-damping, and viscous-damping matrices for the selected sea state.
3. Inspect the data and derived model with the plotting and modal-analysis functions.
4. Run [`SIMhydroVessel`](../CRAFT/SIMhydroVessel.m) to simulate maneuvering, currents, irregular-wave forces, and autopilot or dynamic-positioning control.

Example:

```matlab
load testShip.mat
vessel = computeManeuveringModel(vessel);
plotABC(vessel,'A');
plotABC(vessel,'B');
plotBv(vessel);
```

## Principal Functions

| Function | Purpose |
| --- | --- |
| [`vessels_wamit/wamit2vessel.m`](vessels_wamit/wamit2vessel.m) | Import WAMIT output into an MSS vessel structure. |
| `computeManeuveringModel.m` | Compute power-based constant hydrodynamic and viscous-damping matrices. |
| [`utils/vessel2ss.m`](utils/vessel2ss.m) | Identify state-space radiation-force models from frequency-dependent vessel data using the FDI toolbox. |
| `plotABC.m` | Plot added mass, potential damping, or restoring matrices. |
| `plotAB_eq.m` | Compare frequency-dependent matrices with their power-based equivalents. |
| `plotBv.m` | Compare potential, equivalent, viscous, and total damping. |
| [`plotRAO.m`](plotRAO.m) | Plot motion and force RAO amplitudes and phases for selected headings, using colored or black-and-white lines. |
| [`utils/plotTF.m`](utils/plotTF.m) | Plot motion or force RAOs. |
| [`utils/plotWD.m`](utils/plotWD.m) | Plot second-order mean wave-drift loads. |
| [`vesselPeriods.m`](../LIBRARY/modeling/vesselPeriods.m) | Compute coupled or decoupled heave/roll/pitch periods, damped and undamped natural frequencies, and damping ratios. |
| `Hoerner.m` and `cylinderDrag.m` | Hydrodynamic drag-coefficient utilities. |

Supporting numerical functions are located in [`utils`](utils/), plotting helpers in [`utils/plotting`](utils/plotting/), and WAMIT geometry tools in [`utils/gdf`](utils/gdf/). Radiation-model identification is documented in the [FDI Toolbox documentation](../FDI/FDI-Toolbox.md).

`computeManeuveringModel(vessel)` uses a fixed JONSWAP reference at `omega_p = 1.0` rad/s with `gamma = 3.3`; pass a different peak explicitly when required. Equivalent matrices are recomputed in memory from the frequency-dependent data. Damping inputs are read from `vessel.powerBased` when available. All catalogue files store these inputs; `wamit2vessel` prompts with editable defaults before saving WAMIT files. Viscous damping is additive: `D = B_eq + Bv`. Changing the reference or damping inputs does not require a new hydrodynamic solve; saving the modified structure is a separate action.

Run [`exLoadCondition`](../mssExamples/exLoadCondition.m) to plot heave, roll, and pitch periods versus draft and metacentric height for the bundled supply vessel. Use `exLoadCondition(vessel)` to examine another MSS vessel structure.

## Motion and Force RAO Plots

Run `mssCraft` to list the included vessel-structure MAT-files and all CRAFT dynamics models. For example:

```matlab
load supply.mat vessel
plotRAO(vessel)                     % Default: [0 30 60 90] degrees, colored lines
plotRAO(vessel,[0 30 60 90],false)   % Explicit headings and color setting
plotRAO(vessel,0:30:180,true)        % Seven headings, black-and-white lines
plotRAO(vessel,[],true)             % Default headings, black-and-white lines
```

Figures 1 and 2 show motion RAOs; figures 3 and 4 show force RAOs. Each figure has three rows for three DOFs, with amplitude on the left and phase on the right. The first speed case is used. Headings are specified in degrees and must be present in `vessel.headings`; no interpolation is performed.
