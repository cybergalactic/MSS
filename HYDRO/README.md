# HYDRO Library

HYDRO imports, processes, inspects, and converts seakeeping data for use in MSS. The common `vessel` structure stores rigid-body properties, frequency-dependent added mass and potential damping, hydrostatic restoring matrices, response amplitude operators (RAOs), and wave-drift data. The functions and included data are compatible with MATLAB and GNU Octave.

## Hydrodynamic Data Sources

| Source | License | Included cases and instructions |
| --- | --- | --- |
| ShipX (VERES) | Commercial | [`vessels_shipx`](vessels_shipx/) |
| WAMIT | Commercial | [`vessels_wamit`](vessels_wamit/) |
| Capytaine through MSS-Capytaine | Open source | [`vessels_capytaine`](vessels_capytaine/) |

[MSS-Capytaine](https://github.com/cybergalactic/MSS-Capytaine) computes 6-DOF linear potential-flow hydrodynamics with the open-source Capytaine solver and exports the results in the MSS `vessel` format. Pre-generated Capytaine examples are included and do not require Python unless they are regenerated.

## Typical Workflow

1. Import ShipX data with `veres2vessel`, import WAMIT data with `wamit2vessel`, or load a vessel generated by MSS-Capytaine.
2. Use `computeManeuveringModel` to form constant power-based added-mass, potential-damping, and viscous-damping matrices for the selected sea state.
3. Inspect the data and derived model with the plotting and modal-analysis functions.
4. Run [`SIMhydroVessel`](../CRAFT/SIMhydroVessel.m) to simulate maneuvering, currents, irregular-wave forces, and autopilot or dynamic-positioning control.

Example:

```matlab
load testShip.mat
vessel = computeManeuveringModel(vessel);
plotABC(vessel,'A');
plotABC(vessel,'B');
plotBv(vessel);
```

## Principal Functions

| Function | Purpose |
| --- | --- |
| `veres2vessel.m` | Import ShipX/VERES output into an MSS vessel structure. |
| `wamit2vessel.m` | Import WAMIT output into an MSS vessel structure. |
| `computeManeuveringModel.m` | Compute power-based constant hydrodynamic and viscous-damping matrices. |
| `vessel2ss.m` | Identify state-space radiation-force models from frequency-dependent vessel data. |
| `plotABC.m` | Plot added mass, potential damping, or restoring matrices. |
| `plotAB_eq.m` | Compare frequency-dependent matrices with their power-based equivalents. |
| `plotBv.m` | Compare potential, equivalent, viscous, and total damping. |
| `plotTF.m` | Plot motion or force RAOs. |
| `plotWD.m` | Plot second-order mean wave-drift loads. |
| `shipPeriods.m` and `DPperiods.m` | Compute natural periods and frequencies. |
| `loadcond.m` | Examine heave, roll, and pitch periods versus loading parameters. |
| `Hoerner.m` and `cylinderDrag.m` | Hydrodynamic drag-coefficient utilities. |

Supporting numerical functions are located in [`utils`](utils/), ShipX/VERES readers in [`utils/readdata`](utils/readdata/), and plotting helpers in [`utils/plotting`](utils/plotting/). WAMIT geometry tools are located in [`gdf`](gdf/). Radiation-model identification is documented in the [FDI README](../FDI/README.md).
